# 精确停车控制（编码器零速判定 + 短停）

## What to build

在 `task.c` 中实现一个可靠的"减速→停稳→再启动"动作原语。当前代码中 `task_running=0` 会立即切断动力（`base_speed=0`），但没有判断车辆是否真正停稳，也没有控制停车时长。

实现一个 `Task_Stop_And_Wait()` 或类似的状态机辅助函数：

1. 减速阶段：将 `base_speed` 从当前值平滑降至 0（可用简单的线性递减）
2. 停稳判定：检测左右编码器速度均接近 0（如 `|current_v_left| < 5 && |current_v_right| < 5`）
3. 保持停车：停车后保持 `base_speed=0` 持续一段时间（如 500ms~1000ms，用计数器实现）
4. 再启动：停车时长满足后，恢复 `base_speed` 为正常行驶值

这个动作原语将被任务(3)和任务(4)在需要停车的节点调用。

实现位置：在 `task.c` 的任务函数分区内新增静态辅助函数，或在各 `Run_Task_*` 函数内内联实现。

## Acceptance criteria

- [ ] 实现减速逻辑（`base_speed` 平滑降至 0）
- [ ] 实现停稳判定（编码器速度接近 0）
- [ ] 实现停车保持时长控制（计数器，约 500ms~1000ms）
- [ ] 停车完成后可恢复行驶
- [ ] 逻辑可在 `Run_Task_3` 和 `Run_Task_4` 中复用
