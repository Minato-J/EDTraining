## 项目简介

本项目为 2026 年全国大学生电子设计竞赛（电赛）智能小车参赛作品。小车采用 STM32F407VET6 作为主控芯片，K230 摄像头模组进行 6 路灰度视觉循迹，JY901S 陀螺仪做航向角姿态保持，TB6612 双 H 桥驱动双轮差速小车沿指定的环形赛道自动行驶。

**核心能力**：
- 视觉循迹 + IMU 姿态保持双模切换（直线/弧段自适应）
- 增量式双环 PID 控制（速度环 + 角度环）
- 多任务状态机调度（5 个赛道任务，覆盖直线、弧段、对角线、多圈连续）

**硬件清单**：

| 模块 | 型号/接口 | 功能 |
|------|-----------|------|
| 主控 | STM32F407VET6（ARM Cortex-M4, 168 MHz） | 全部实时控制逻辑 |
| 视觉 | K230 摄像头 USART3（115200 bps） | 6 路灰度循迹，每帧返回 1 字节传感器状态 |
| 陀螺仪 | JY901S USART2（9600 bps） | Yaw 角 + 角速度，角度闭环与盲开保持 |
| 电机驱动 | TB6612FNG TIM3 PWM（CH1=左, CH2=右） | 双路 H 桥驱动左右轮 |
| 编码器 | TIM2（左）/ TIM4（右）编码器模式 | 实时轮速反馈 |
| 显示 | 0.96" OLED（PB6=SCL, PB7=SDA 软件 I2C） | 任务状态与调试信息 |
| 按键 | PB0（切换任务）、PB1（启动） | 人机交互 |
| 定时器 | TIM6（~20 ms 中断） | PID 控制器定时节拍 |

## 软件架构

### 控制架构（TIM6 中断，~20 ms 周期）

`main.c` 的 `HAL_TIM_PeriodElapsedCallback(TIM6)` 中包含全部实时控制逻辑，执行顺序如下：

1. **节点计数去抖** — 检测 `line_sensor_data` 从有线→无线的边沿变化，触发节点计数 +1，带 200 ms 去抖窗口防止误触发
2. **角度突变过滤** — 单周期 Yaw 变化 >30° 时丢弃异常读数
3. **双模切换**：
   - `line_sensor_data == 0x00`（全白/丢线）→ **盲开模式**：角度环 PID 锁定 `target_angle`
   - 否则 → **循迹模式**：K230 转弯量修正航向，同时同步 `target_angle` 防止切回盲开时抖动
4. **差速合成** — 左轮 = `base_speed + ff_diff - turn_out`，右轮 = `base_speed - ff_diff + turn_out`
5. **速度环 PID** — 左右轮独立增量式 PID 闭环，配合编码器低通滤波

### 两种导航策略

| 策略 | 适用任务 | 说明 |
|------|---------|------|
| **count 驱动** | Task 1, 2, 5 | 节点计数器直接决定路段（直线/弧段），每 case 设置 `target_angle` + `base_speed` + `ff_diff`，依赖节点检测可靠性 |
| **航点状态机** | Task 3, 4 | 多状态流转，每状态包含旋转（调整目标角度）和推进（等待 count 触发），支持连续多圈 |

### 双环 PID 参数（增量式）

| 控制环 | Kp | Ki | Kd | 说明 |
|--------|----|----|-----|------|
| 左轮速度环 | 0.9 | 0.12 | — | 编码器反馈闭环 |
| 右轮速度环 | 0.8 | 0.12 | — | 编码器反馈闭环 |
| 角度环 | 1.2 | — | 0.6 | 陀螺仪 Yaw 角闭环（无积分项） |

## 快速开始

### 编译环境

- **IDE**: Keil MDK (ARM Compiler 5/6)
- **工程文件**: `H0/MDK-ARM/` 下的 `.uvprojx` 文件
- 使用 Keil IDE 打开工程，编译后通过 ST-Link / J-Link 烧录

### K230 端

K230 开发板运行 `H0/untitled_1.py`（MicroPython），负责采集 6 路灰度并通过 UART3 以 115200 bps 发送给 STM32。帧格式：`0xAA 0x55 [data]`，data 的 bit0~bit5 对应 6 路灰度传感器状态。

## 按键操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **PB0**（Shift） | 切换任务编号 | 停车状态下循环切换 Task 1 → 2 → 3 → 4 → 5，比赛当天建议限制到 Task 4 |
| **PB1**（Start） | 启动当前任务 | 记录当前 Yaw 角为 `Yaw_Offset`，重置所有状态（count、圈数、状态机），开始行驶 |

**启动流程**：
1. 上电后 OLED 显示当前任务编号
2. 按 PB0 切换到目标任务
3. 将小车摆放至起点（A 点），按 PB1 启动
4. 任务完成或出现异常时小车停车

## 通信协议

### K230 → STM32（视觉数据）

- 接口：UART3, 115200 bps
- 帧格式：`0xAA` `0x55` `[data_byte]`
- data_byte 的 bit0~bit5 分别对应 6 路灰度（1 = 检测到黑线）
- 解析模块：`H0/Drive/k230_track.c`（输出转弯量 ±3~±27）

### JY901S → STM32（陀螺仪）

- 接口：UART2, 9600 bps
- 帧格式：11 字节（0x55 + type + data + checksum）
- 解析模块：`H0/Drive/wit_imu.c`（字节状态机解析 Yaw/角速度）

### 调试串口

- 接口：UART1, 115200 bps
- 用途：开发阶段 printf 调试输出
