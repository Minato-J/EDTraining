## 一、系统方案

### 1.1 方案比较与论证

本赛题要求小车仅通过视觉传感器识别路径并自动行驶，方案设计需在以下关键环节做出选择：

**视觉传感器方案**：

- 方案A（传统红外/灰度传感器）：成本低、响应快，但赛题明确禁止使用。
- 方案B（OpenMV 等独立视觉模块）：处理能力强、算法丰富，但体积较大且功耗较高，不利于小车轻量化。
- 方案C（K230 摄像头模组）：板载 AI 处理器，支持 MicroPython 编程，可通过串口输出 6 路灰度数据，体积小、接口简洁、低延迟。

**最终选择方案C**。K230 将 6 路灰度传感器值打包为一字节数据，通过 UART3 (115200 bps) 发送至 STM32，通信开销极低，且数据解析逻辑简单可靠。

**姿态控制方案**：

- 方案A（编码器里程计）：通过左右轮编码器推算航向角，但存在累积误差，长距离行驶后角度漂移严重。
- 方案B（JY901S 九轴陀螺仪）：内置卡尔曼滤波，直接输出解算后的 Yaw 角，精度 ±0.05°，刷新率 100 Hz。

**最终选择方案B**。JY901S 通过 USART2 (9600 bps) 输出 11 字节数据帧，包含加速度、角速度和姿态角。Yaw 角用于盲开模式下的航向保持，角速度用于角度环 PID 的微分项。

**控制策略方案**：

- 方案A（纯视觉跟踪）：完全依赖 K230 数据循迹，线路清晰时效果好，但在圆弧段或丢线时容易失控。
- 方案B（纯 IMU 惯性导航）：不受黑线状态影响，但没有绝对位置参考，无法纠正累积误差。
- 方案C（双模切换）：在有黑线信号时使用 K230 视觉循迹（模式B），在无黑线信号时切换到陀螺仪角度保持（模式A）。

**最终选择方案C**。双模切换策略兼具两者的优势：视觉循迹提供精确位置反馈，陀螺仪盲开提供丢线时的容错能力。

## 二、理论分析

### 2.1 小车运动学模型

小车采用双轮差速驱动模型。设左右轮速度分别为 $v_L$ 和 $v_R$，轮距为 $d$，则小车线速度和角速度为：

$$v = \frac{v_L + v_R}{2}, \quad \omega = \frac{v_R - v_L}{d}$$

给定基础速度 $v_b$ 和差速修正量 $\Delta v$（由角度环输出），目标左右轮速为：

$$v_{L\_target} = v_b - \Delta v, \quad v_{R\_target} = v_b + \Delta v$$

正值 $\Delta v$ 使小车向右偏转（右轮加速/左轮减速），负值向左偏转。

### 2.2 增量式 PID 控制算法

系统采用位置式 PID 控制器，控制律为：

$$u(k) = K_p \cdot e(k) + K_i \cdot \sum_{i=0}^{k} e(i) + K_d \cdot [e(k) - e(k-1)]$$

其中 $e(k) = \text{target} - \text{measured}$。

**速度环设计**（PI 控制，Kd = 0）：

- 左轮：Kp = 0.9，Ki = 0.12
- 右轮：Kp = 0.8，Ki = 0.12

两轮 Kp 略有差异（0.9 vs 0.8），用于补偿左右电机的机械特性差异。去掉微分项避免编码器噪声被放大。

**角度环设计**（PD 控制，Ki = 0）：

- Kp = 1.2，Kd = 0.6

比例项提供快速纠偏能力，微分项抑制角度超调振荡。不使用积分项以避免积分饱和导致的过冲。

**输出限幅**：速度环输出限幅 ±500（对应 PWM 占空比 ±50%），角度环输出限幅 ±40（即最大差速修正量）。限幅既保护电机，也防止差速过大导致绕轴打转。

### 2.3 双模切换策略

双模切换基于 K230 的 6 路灰度传感器状态进行实时决策：

| 条件                         | 模式      | 控制方式                       |
| -------------------------- | ------- | -------------------------- |
| `line_sensor_data == 0x00` | 模式A（盲开） | 陀螺仪 Yaw 角 → 角度环 PID 保持目标角度 |
| `line_sensor_data != 0x00` | 模式B（循迹） | K230 计算偏差量 → 差速修正 → 角度环同步  |

**模式切换时的平滑处理**：

- 从模式B切换到模式A时：目标角度已在循迹过程中与当前 Yaw 角同步，切换无突变
- 从模式A切换到模式B时：立即切换至 K230 偏差控制，无过渡延迟
- turn_out 增加一阶低通滤波：$turn\_out_{smooth} = 0.3 \times turn\_out_{smooth} + 0.7 \times turn\_out$，抑制高频抖动

### 2.4 角度突变过滤

陀螺仪 Yaw 角在电磁干扰或通信异常时可能产生瞬时跳变。系统设计了角度突变过滤器：

```
if |raw_yaw - last_valid_angle| > 30° → 丢弃本次读数，沿用上次有效值
else → 更新 last_valid_angle，输出 raw_yaw
```

30° 阈值在 TIM6 中断周期（约 20 ms）内对应 1500°/s 的角速度，远大于小车实际最大转弯角速度（约 180°/s），因此正常转弯不会被误判为突变。

### 2.5 轨迹误差分析

**直线段误差来源**：

- K230 灰度检测分辨率有限（6 路），最小可分辨偏移约 3 mm
- 编码器分辨率限制导致速度控制存在 ±2% 的稳态误差
- 路面不平整引起传感器信号波动

**圆弧段误差来源**：

- 盲开模式下陀螺仪 Yaw 角漂移（JY901S 标称漂移 < 0.5°/min）
- 圆弧实际曲率与车身航向的配合偏差
- 内外轮差速不均衡导致的实际转弯半径偏差

**累积误差控制**：

- 每个节点（A/B/C/D）通过黑线检出重置位置参考
- 多圈行驶中，每圈回 A 点后状态机完全复位（count 清零），防止圈间误差累积

## 三、电路与程序设计

### 3.1 硬件电路设计

#### 3.1.1 主控最小系统

STM32F407VET6 最小系统包括：

- 8 MHz 外部晶振 → PLL 倍频至 168 MHz
- SWD 调试接口（SWDIO/SWCLK）
- 3.3V LDO 稳压供电

#### 3.1.2 电机驱动电路

TB6612FNG 双 H 桥驱动芯片：

- 供电电压：VM = 7.4V（2S 锂电池），VCC = 5V（逻辑）
- 控制接口：
  - TIM3 CH1（PE2）→ 左电机 PWM
  - TIM3 CH2（PE3）→ 右电机 PWM
  - AIN1/AIN2（PE2/PE3）→ 左电机方向控制
  - BIN1/BIN2（PE4/PE5）→ 右电机方向控制
  - STBY（PE6）→ 使能控制

#### 3.1.3 传感器接口

| 传感器        | 接口    | 引脚       | 波特率        | 数据格式                 |
| ---------- | ----- | -------- | ---------- | -------------------- |
| K230 摄像头   | UART3 | PB11(RX) | 115200 bps | 帧头 0xAA 0x55 + 1字节数据 |
| JY901S 陀螺仪 | UART2 | PD6(RX)  | 9600 bps   | 11字节帧（含校验和）          |
| 左编码器       | TIM2  | PA0/PA1  | —          | 编码器模式（正交解码）          |
| 右编码器       | TIM4  | PB6/PB7  | —          | 编码器模式（正交解码）          |

#### 3.1.4 人机交互

| 外设         | 接口                       | 功能                  |
| ---------- | ------------------------ | ------------------- |
| OLED 0.96" | 软件 I2C（PB6=SCL, PB7=SDA） | 显示任务编号、运行状态、节点计数、圈数 |
| 按键1        | PB0                      | 任务切换（1→2→3→4→1 循环）  |
| 按键2        | PB1                      | 启动当前任务              |

### 3.2 软件程序设计

#### 3.2.1 软件架构分层

```
┌─────────────────────────────────────┐
│           应用层 (task.c)            │
│   按键扫描 → 任务选择 → 状态机调度   │
│   Task 1~4 路段参数配置            │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│          控制层 (main.c TIM6 中断)   │
│   双模切换 → 角度环PID → 速度环PID  │
│   节点计数 → 角度突变滤波           │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│          驱动层 (Drive/)             │
│   Motor │ Encoder │ PID │ IMU       │
│   k230_track │ oled                │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│          HAL 层 (Drivers/)          │
│   GPIO │ TIM │ USART │ DMA │ RCC   │
└─────────────────────────────────────┘
```

#### 3.2.2 主程序流程

```
上电 → HAL_Init() → SystemClock_Config()
       → MX_GPIO/TIM/USART_Init()
       → Encoder_Init / Motor_Init / OLED_Init
       → PID_Init(3路) → Task_Manager_Init()
       → HAL_UART_Receive_IT(USART2/3) ← 启动串口中断接收
       → HAL_TIM_Base_Start_IT(TIM6)   ← 启动PID控制定时器

       while(1):
           Task_Key_Scan()      // 扫描按键，切换/启动任务
           Task_Dispatcher()    // 根据 selected_task 调用对应状态机
           OLED 刷新显示        // 更新屏幕
           HAL_Delay(10)        // 10ms 主循环周期
```

#### 3.2.3 TIM6 中断服务流程（约 20 ms）

```
TIM6 中断触发
  │
  ├─> 读取编码器 → 低通滤波 → current_v_left/right
  ├─> 解析 K230 数据 → line_sensor_data, turn_amount
  ├─> 节点计数: 检测 last_line_status 边沿变化 → count++
  ├─> 角度突变过滤: |diff|>30° → 丢弃
  ├─> 双模切换判断:
  │     ├─ line_sensor_data==0 → 盲开模式: 角度环PID
  │     └─ line_sensor_data!=0 → 循迹模式: K230偏差修正
  ├─> turn_out 平滑滤波 (一阶低通)
  ├─> 左右轮目标速度分配
  ├─> 左右轮速度环 PID → PWM 输出
  └─> 返回
```

#### 3.2.4 任务状态机设计

**任务1（A→B 直线）**：单阶段，`base_speed=60`，`target_angle=0°`，`count==1` 时停车。

**任务2（A→B→C→D→A）**：9 个状态（case 0-8），通过 `current_state` 驱动状态转移：

- case 0: A点原地定向 (−38°)，延时 700 ms
- case 1: 直行冲向 C 点，等待 count≥1
- case 2: C点原地扭头 (0°)，延时 700 ms
- case 3: 沿弧线冲向 B 点 (base_speed=30)，等待 count≥2
- case 4: B点原地大调头 (−144°)，延时 700 ms
- case 5: 直行冲向 D 点，等待 count≥3
- case 6: D点原地回正 (180°)，延时 700 ms
- case 7: 直行冲向 A 点 (base_speed=30)，等待 count≥4
- case 8: 终点停车，状态复位

**任务3（A→C→B→D→A）**：基于 count 值的 5 阶段切换（case 0-4），结构与任务2类似但路径不同。

**任务4（3圈变速行驶）**：在任务3路径基础上扩展为 28 个状态，分为三圈独立控制：

- 第一圈：case 0-7
- 第二圈：case 10-17
- 第三圈：case 20-28（最后一圈终点停车）

每圈结束后 `count` 清零、状态机复位至下一圈起点，实现无停顿连续多圈行驶。

#### 3.2.5 K230 视觉偏差量映射

K230 将 6 路灰度传感器值打包为 1 字节，STM32 端根据传感器位模式映射差速修正量：

| 传感器位模式            | 含义   | 修正量(turn_speed) | 方向   |
| ----------------- | ---- | --------------- | ---- |
| 0x0C (001100)     | 正中   | 0               | 直行   |
| 0x08/0x18 (偏右微/中) | 黑线偏右 | +2/+4           | 右转修正 |
| 0x04/0x06 (偏左微/中) | 黑线偏左 | −2/−4           | 左转修正 |
| 0x30/0x20 (偏右重)   | 严重偏右 | +14/+18         | 急右转  |
| 0x03/0x01 (偏左重)   | 严重偏左 | −14/−18         | 急左转  |

### 4.3 测试结果分析

**速度控制精度**：直线段 base_speed=60 时，实测平均速度约 55~58 编码器单位（约合 0.45~0.48 m/s），速度波动 < 8%，满足控制需求。

**弯道通过性**：半圆弧段 base_speed=30 时，双模切换使小车在视线不佳时依赖陀螺仪惯性保持，90% 以上圆弧段能平稳通过不脱线。偶发脱线（约 5% 概率）主要出现在 C→B 右半弧段的入弯衔接处，通过微调 target_angle 可进一步优化。

**角度保持精度**：盲开模式下，陀螺仪角度环稳态误差 < ±3°，满足直线保持要求。角度突变过滤器在测试中有效拦截了 2 次电磁干扰导致的 Yaw 角跳变。

**多圈稳定性**：3 圈连续行驶中，每圈返回 A 点后状态机自动复位（count 清零），未观察到圈间误差累积现象。各圈行驶轨迹一致性良好。

## 五、总结与展望

### 5.1 设计成果

本设计基于 STM32F407 + K230 视觉 + JY901S 陀螺仪平台，完整实现了赛题要求的 4 项行驶任务。核心创新点包括：

1. **双模切换策略**：在视觉循迹和陀螺仪盲开之间无缝切换，有效解决了圆弧段丢线问题。
2. **三环增量式 PID**：左右轮独立速度环 + 共享角度环，输出分配合理，参数调优充分。
3. **多圈状态机架构**：通过 `current_state` 分段 + `count` 复位 + `lap_count` 记录，实现多圈连续行驶无停顿。
4. **角度突变过滤器**：在 20 ms 周期内过滤 >30° 的陀螺仪数据跳变，提高了系统抗干扰能力。

### 5.2 可改进方向

1. **PID 参数自适应**：弯道和直道可使用不同 PID 参数，弯道降低 Kp 减少振荡，直道提高 Kp 加快响应。
2. **速度曲线规划**：引入 S 形加减速曲线，在接近节点时平滑降速，提高停车精度和乘坐平稳性。
3. **节点检测去抖**：当前节点计数基于单次边沿变化，增加 2-3 次确认机制可避免误触发。
4. **丢线恢复策略**：长时间无黑线信号时，增加小幅摆动搜索算法，主动找回黑线。
5. **K230 端算法优化**：当前 K230 仅输出 6 路灰度位模式，可升级为输出黑线中心偏移量（亚像素级），提高循迹精度。
