# Triage Labels

技能使用五个标准分类角色。此文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能中的标签       | 本仓库标签        | 含义                       |
| ----------------- | ----------------- | -------------------------- |
| `needs-triage`    | `needs-triage`    | 维护者需要评估此问题         |
| `needs-info`      | `needs-info`      | 等待提交者补充更多信息       |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可供 AFK agent 领取 |
| `ready-for-human` | `ready-for-human` | 需要人工实现                |
| `wontfix`         | `wontfix`         | 不予处理                    |

当技能提到某个角色（如"打上 AFK-ready 分类标签"），请使用此表中对应的标签字符串。

如需自定义，编辑右侧列以匹配你实际使用的词汇。
