### car_control.c — Car_ControlLoop 函数体重写

逐处替换：

| 旧（extern 读取） | 新 |
|---|---|
| `current_angle` | `in.current_angle` |
| `&pid_angle` | `angle_pid_ptr` |
| `line_sensor_data` | `in.line_sensor_data` |
| `k230_data_valid` | `in.k230_data_valid` |

| 旧（extern 写入） | 新 |
|---|---|
| `target_v_left = 0`（CTRL_PARK） | `out.target_v_left = 0` |
| `target_v_right = 0`（CTRL_PARK） | `out.target_v_right = 0` |
| `target_v_left = base_speed + ...`（差速合成） | `out.target_v_left = ...` |
| `target_v_right = base_speed - ...`（差速合成） | `out.target_v_right = ...` |
| `task_running = 0`（盲开超时） | `out.emergency_stop = 1` |
| 盲开超时路径中 `target_v_left = 0; target_v_right = 0; return;` | `out.target_v_left = 0; out.target_v_right = 0; out.emergency_stop = 1; return out;` |
