## 问题

`car_control.c` 的 `Car_ControlLoop()` 通过 `extern` 直接读取 5 个外部模块的全局变量，并写入 3 个。每条 extern 都是一条跨模块数据泄漏路径，导致 car_control 模块无法脱离 STM32 硬件独立测试。

当前 extern 泄漏清单（[car_control.c:32-36](Drive/car_control.c#L32-L36)）：

```c
extern float current_angle;                    // main.c
extern PID_TypeDef pid_angle;                  // main.c
extern int16_t target_v_left;                  // main.c（读写）
extern int16_t target_v_right;                 // main.c（读写）
extern volatile uint16_t task_running;         // task.c（写入）
```

加上通过 `#include` 隐式访问的全局变量：
- `line_sensor_data`（k230_track.c）
- `k230_data_valid`（k230_track.c）

**删除测试**：当前 Car_ControlLoop 无法在 PC 上单测——必须先正确设置 5+ 个 extern 全局变量，且 `PID_Compute` 依赖 `pid_angle` 结构体的完整初始化。

## 方案

### 核心思路

将 `Car_ControlLoop` 从"隐式读写全局变量"改为"显式参数传入 + 返回值传出"。

### 设计决策（已确认）

| # | 决策 | 选择 |
|---|------|------|
| 1 | pid_angle 传递方式 | **Init 时指针注入**（零每 tick 开销） |
| 2 | 紧急停车信号回传 | **输出 struct 中的 emergency_stop flag** |
| 3 | K230/WIT 模块依赖 | **保留**（纯计算函数的 #include 依赖是正常模块边界） |

### 新接口

```c
// ==== 每 tick 输入（ISR 在调用前组装）====
typedef struct {
    float   current_angle;      // main.c 角度过滤器输出
    uint8_t line_sensor_data;   // K230 6 路灰度原始值
    uint8_t k230_data_valid;    // K230 帧新鲜度标志
} Car_SensorInputs;

// ==== 每 tick 输出（ISR 在调用后消费）====
typedef struct {
    int16_t target_v_left;      // 左轮目标速度 → speed PID
    int16_t target_v_right;     // 右轮目标速度 → speed PID
    uint8_t emergency_stop;     // 盲开超时 → ISR 设 task_running=0
} Car_ControlOutputs;
```

### 签名变更

| 旧 | 新 |
|---|---|
| `void Car_ControlLoop(void)` | `Car_ControlOutputs Car_ControlLoop(Car_SensorInputs in)` |

### 需新增的 Init 参数

```c
// Car_Init 新增 pid_angle 指针参数，存为内部 static 指针
void Car_Init(PID_TypeDef *angle_pid);
```

## main.c ISR 胶水代码（参考）

```c
// 旧: Car_ControlLoop();  // 隐式读写 5+ 个全局变量
// 新:
Car_SensorInputs in = {current_angle, line_sensor_data, k230_data_valid};
Car_ControlOutputs out = Car_ControlLoop(in);

target_v_left  = out.target_v_left;
target_v_right = out.target_v_right;
if (out.emergency_stop) task_running = 0;
// 继续 speed PID + Motor_SetSpeed...（不变）
```

## 验证标准

1. `car_control.c` 中不再有 `extern float current_angle` / `extern int16_t target_v_left` / `extern int16_t target_v_right` / `extern volatile uint16_t task_running` 声明
2. `extern PID_TypeDef pid_angle` 替换为 `static PID_TypeDef* angle_pid_ptr`（Init 注入）
3. `Car_ControlLoop` 函数体内所有 `current_angle` → `in.current_angle`，所有 `target_v_left = ` → `out.target_v_left = `
4. 盲开超时路径不再写 `task_running = 0`，改为 `out.emergency_stop = 1`
5. main.c 中 `Car_Init()` 调用处补上 `&pid_angle` 参数
6. Keil 编译零错误零警告
7. 逻辑行为完全等价——不改变任何运行时决策
