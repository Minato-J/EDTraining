## 改动

### 1. car_control.h — 新增两个 struct

```c
// 每 tick 输入（ISR 在调用前组装）
typedef struct {
    float   current_angle;      // main.c 角度过滤器输出
    uint8_t line_sensor_data;   // K230 6 路灰度原始值
    uint8_t k230_data_valid;    // K230 帧新鲜度标志
} Car_SensorInputs;

// 每 tick 输出（ISR 在调用后消费）
typedef struct {
    int16_t target_v_left;      // 左轮目标速度 → speed PID
    int16_t target_v_right;     // 右轮目标速度 → speed PID
    uint8_t emergency_stop;     // 盲开超时 → ISR 设 task_running=0
} Car_ControlOutputs;
```

### 2. car_control.h — Car_Init 签名改

```c
// 旧: void Car_Init(void);
// 新: void Car_Init(PID_TypeDef *angle_pid);
```

### 3. car_control.h — Car_ControlLoop 签名改

```c
// 旧: void Car_ControlLoop(void);
// 新: Car_ControlOutputs Car_ControlLoop(Car_SensorInputs in);
```

注意：头文件需前向声明 `PID_TypeDef`（来自 `pid.h`），或 `#include "pid.h"`。

### 4. car_control.c — pid_angle 指针化

```c
// 删除: extern PID_TypeDef pid_angle;
// 新增:
static PID_TypeDef *angle_pid_ptr = NULL;

void Car_Init(PID_TypeDef *angle_pid) {
    angle_pid_ptr = angle_pid;
    ctrl_mode = CTRL_PARK;
    target_angle = 0.0f;
    base_speed   = 0;
    ff_diff      = 0;
    blind_ticks  = 0;
    turn_out_smooth = 0.0f;
}
```

### 5. main.c — Car_Init 调用处补参数

```c
// 旧: Car_Init();
// 新: Car_Init(&pid_angle);
```
