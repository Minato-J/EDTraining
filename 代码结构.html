1 项目总览

项目内容
MCUSTM32F407VETx (Cortex-M4, 168MHz)
开发环境STM32CubeIDE (.ioc) + MDK-Keil (ARM Compiler 5/6)
HAL 库STM32F4xx HAL Driver v1.x
视觉模块K230 (Canaan) — MicroPython, 640x480 摄像头
IMU 模块WIT (维特智能) JY901S — 9轴姿态传感器, USART2 通信
电机驱动TB6612 双路电机驱动 (H桥)
电机类型带编码器的直流减速电机 x 2 (左右独立)
用户代码量约 2100 行 (不含 HAL 库)
分析日期2026-05-21

整体完成度

基础电控层: 95% (硬件驱动 + PID + IMU 全部就绪, PWM 归一化修复)
视觉巡线: 100% (7-byte 协议 + 连续偏差 + 置信度 + 顶点检测全部完成)
导航与任务: 100% (路径状态机 + 航位推算 + 双模式切换 + 停车全部完成)
总体: 95% (PID 上车整定待验证, OLED 待 CubeMX I2C 配置)

3 已完成项目清单

1. 电机驱动模块 完成

文件: Drive/Motor.c, Drive/Motor.h

硬件: TB6612, TIM3 PWM (PA6/PA7), GPIO PE2~PE6

  • Motor_Init() — 启动PWM, 使能STBY
  • Motor_SetSpeed_A/B() — 双向速度控制 (正=前进, 负=后退)
  • PWM 归一化: speed*99/1000 → TIM3 CCR 0-99
  • 限幅: ±1000

对应计划: 第2天 — 电机驱动

2. 编码器测速模块 完成

文件: Drive/encoder.c, Drive/encoder.h

硬件: TIM2 (左 PA0/PA1), TIM4 (右 PD12/PD13), 编码器模式

  • Encoder_Init() — 启动双路编码器
  • Encoder_Get_Count_Left/Right() — 读取并复位
  • 50Hz IIR滤波: fil = 0.7*fil_old + 0.3*raw

对应计划: 第3天 — 编码器测速

3. PID 控制器模块 完成

文件: Drive/pid.c, Drive/pid.h

  • 增量型 PID: Kp, Ki, Kd, 积分限幅
  • 3 个实例: 左轮(Kp0.9/Ki0.12), 右轮(Kp0.8/Ki0.12), 角度(Kp1.2/Kd0.6)
  • 输出限幅: 速度环±500, 角度环±40

对应计划: 第4天 — 速度闭环

4. WIT IMU 姿态模块 完成

文件: Drive/wit_imu.c, Drive/wit_imu.h

硬件: JY901S, USART2 (PA2/PA3, 115200 baud)

  • 11字节帧解析: 0x55 + 数据9 + 校验和1
  • 加速度(0x51)/角速度(0x52)/角度(0x53)
  • Yaw角滤波: >30°跳变拒绝

对应计划: 第6天 — 陀螺仪集成

5. 串口通信模块 完成

文件: Core/Src/usart.c, stm32f4xx_it.c

  • USART1: 115200 (PA9/PA10) — printf 调试输出
  • USART2: 115200 (PA2/PA3) — IMU + K230 数据接收
  • 协议复用: 根据帧头 (0xAA/0x55) 自动区分 K230/IMU

对应计划: 第8天 — MCU与模块串口通信

6. GPIO 电机控制引脚 完成

文件: Core/Src/gpio.c

  • AIN1(PE2), AIN2(PE3) — 左轮方向
  • BIN1(PE4), BIN2(PE5) — 右轮方向
  • STBY(PE6) — TB6612 待机

7. 定时器外设配置 完成

文件: Core/Src/tim.c

定时器功能配置
TIM2左编码器Encoder Mode TI12
TIM3电机 PWMPWM Mode1, 20kHz, CCR 0-99
TIM4右编码器Encoder Mode TI12
TIM6控制定时器50Hz (20ms) 中断

8. K230 视觉巡线 (Python) 完成

文件: untitled_1.py

  • 6 ROI 灰度检测 + 加权质心法 → 连续偏差值 ±500
  • 置信度 0-100 (ROI覆盖 60% + 对比度 40%)
  • 顶点检测: 偏差突变>80 + 交叉路口≥5 ROI + 30帧去抖
  • 7-byte 协议: 0xAA devL devH conf vFlag csum 0x55

9. 路径状态机 新增

文件: Drive/path_fsm.c, Drive/path_fsm.h

  • 12段查找表: TASK_IDLE → TASK_1-4 → TASK_DONE
  • 双模式: MODE_LINE_FOLLOW / MODE_DEAD_RECKON
  • 顶点防抖 300ms + 距离累积 + 圈数计数
  • TASK_4: 4圈自动循环, 子步跟踪

10. 声光指示 新增

文件: Drive/buzzer.c/h, Drive/led.c/h

  • 蜂鸣器 PB0: 200ms 顶点提示音
  • LED PC13: 3次 200ms 闪烁
  • PathFSM_NotifyVertex() 自动触发
  • TIM6 ISR 驱动 Update 状态机

11. 精准停车控制 新增

文件: Core/Src/main.c (TIM6 ISR)

  • 三段式: 减速(500ms线性→20%) → 微调(低速) → 刹车
  • 停车条件: 视觉偏差<20 + 置信度>30 + 100ms稳定
  • 仅对 is_terminal 段触发

12. OLED 显示驱动 新增

文件: Drive/oled.c, Drive/oled.h

  • SSD1306 128x64 I2C (I2C1: PB6/PB7, 需CubeMX启用)
  • 内嵌 5x7 ASCII 字体, 支持 1x/2x 字号
  • OLED_ShowStatus(): 任务/速度/Yaw/距离/顶点
